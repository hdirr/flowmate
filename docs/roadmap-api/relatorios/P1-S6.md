## Chave em comandos: problema e decisão
- **Problema:** cada comando do Claude Code abre um terminal novo, então `KEY=...` não
  sobrevive entre comandos. A chave acabava escrita em cada comando, e o comando aprovado com
  "sempre permitir" ia para o allowlist com o valor.
- **Decisão (tutor):** opção (b). A chave fica na variável de usuário do Windows
  `FLOWMATE_TEST_KEY`. Os comandos usam só o nome, conferem o tamanho antes de usar e param se
  vier vazia. No fim da Parte 1 o Agadir regenera a chave e atualiza a variável.

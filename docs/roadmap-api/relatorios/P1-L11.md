  - **id que não é UUID** → 404 `lead_not_found`, **sem consultar o banco**;
  - **lead** buscado por `company_id` (da chave) + id. Inexistente ou de outra empresa → 404
    `lead_not_found`;
  - **lead sem contato** → 200 `items: []`;

    pelo `user_id`**, sem e-mail nem nome; o nome sai em `GET /v1/users`;
